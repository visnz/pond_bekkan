# 不可选对象 Bounds / Textured 显示联动

## 目标与范围

按用户要求，物体不可选时 Display As 切为 Bounds，点击激活时切回 Textured，调整完成锁回时再切为 Bounds。外部解除禁选也切回 Textured。
修改仅涉及 New 的不可选对象逻辑、别馆提示、相关测试及本记录，未修改共同维护模块或 Pond 专属文件。功能沿用 core 常驻注册，原生对象可选择性变化在两种界面模式下均可同步。
沿用本轮已读取的个人插件开发技能、项目 AGENTS.md、CLAUDE.md、合并对照清单与模块归属说明。

## 修改文件与实现

- `core/unselectable.py`：新增 `_sync_object_display()`、`_sync_display_modes()` 和 `_on_depsgraph()`。使用对象 session_uid 记录前次禁选状态，只对禁选、刚解锁或面板调整中的对象同步显示；普通可选对象的 Wire/Solid 等设置保留。
- `unlock_and_select()` 成功激活后立即切回 Textured，失败时保留显示方式及选择；LOCK 操作立即切为 Bounds。
- `hide_select` 消息订阅同步原生 UI 变化；依赖图回调检查本次更新的对象，覆盖脚本修改。启用插件、加载文件、撤销/重做时同步已有状态。注销时移除监听并清理运行时缓存。
- 跳过不可编辑或 display_type 只读的数据，不改变隐藏状态或集合限制。显示方式写入原生 Object 属性并随工程保存。
- `ui/bekkan/unselectable_panel.py`：补充“禁选：Bounds · 激活：Textured”提示；操作说明同步更新。
- `tools/test_unselectable.py`：补充启用前锁定对象、外部锁定/解锁、激活/锁回/移出、失败保护、普通对象显示保留、文件重开及监听注销检查。
- `开发计划/模块归属标注.md`：更新两项 New 模块描述，无需修改共同维护清单。

## 调试过程

先在隔离 Blender 5.2.4 查询 display_type 枚举，确认 BOUNDS 与 TEXTURED 名称；探测 hide_select 修改是否触发对象依赖图更新，确认锁定与解除都能触发。
随后在独立 factory-startup 实例复用原生事件模拟测试。列表行点击、同一行再次点击、名称按钮激活、面板锁回及外部脚本锁定/解锁均按预期同步显示，无需手动刷新。
一次性探测和交互脚本位于忽略目录 `temp/`，测试实例已自动退出。未重载、修改或保存用户当前工程。
