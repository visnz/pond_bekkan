# 2026-11-04 搭建类新增「清除所有 Fake User」

## 目标与范围

桶桶要求在别馆「🏗 搭建类」面板加入按钮，一次清除当前 `.blend` 工程所有数据块的 Fake User 标记。

`core/stage.py` 是 Mixed 共同维护文件；本次新增独立的 `StageClearAllFakeUsers`，不改动原有 Pond/Bekkan 操作。入口只加入 Bekkan 专属的 `ui/bekkan/panels.py`，Pond 面板与现有行为不变。已同步更新 `开发计划/模块归属标注.md` 的函数明细和共同维护清单。当前用户是桶桶，已明确要求增加此功能；修改范围及对另一模式的影响在开发前说明。

## 修改

- `core/stage.py`：增加 `object.clear_all_fake_users_visn`。遍历 Blender 5.2 的 `bpy.data.all_ids`，仅将当前为 `True` 的 `use_fake_user` 改为 `False`；链接库或只读数据块跳过并计数。执行前使用 Blender 标准确认弹窗，操作支持 Undo，结束时报告清除和跳过数量。不调用孤立数据清理，也不自动保存工程。
- `ui/bekkan/panels.py`：在「搭建类」面板末尾加入按钮。
- `tools/test_clear_fake_users.py`：隔离后台测试，覆盖多种数据块、全局残留检查、重复执行和别馆面板注册。

## 调试与测试

- Blender 5.2.3 LTS 的独立后台实例确认 `bpy.data.all_ids` 可用，且覆盖多个 ID 类型。
- 首次测试在检查成员时用 `datablock in bpy.data.all_ids`，Blender 集合要求名称字符串而抛出 `TypeError`；测试改为比较 `as_pointer()`，功能实现未受影响。
- `blender --background --factory-startup --python-exit-code 1 --python tools/test_clear_fake_users.py` 通过：测试建立的网格、材质、动作、图片、集合、文本均清除标记；原始场景另有一个带 Fake User 的数据块，也被清除（共 7 个）。数据块未被立即删除，第二次执行报告无待清除项，别馆面板成功注册。
- `core/stage.py` 与 `ui/bekkan/panels.py` 语法检查、`git diff --check` 通过。
