# Fab 材质导入与灯光合成紧凑布局

## 目标与范围

用户提供 Fab 下载后解压的 Worn Concrete Ceiling 文件夹，要求先完成材质导入：
选择文件夹后创建猴头、新材质及 Principled BSDF；只加载 BaseColor、Normal、
Displacement、Specular、Roughness、AO 六种图；AO 不连接颜色输出。
所有图共用 Texture Coordinate → Mapping，Mapping Scale 由 Value 控制。
BaseColor 使用 sRGB，其他图 Non-Color；位移接好但不启用 Displacement and Bump。
入口放在灯光合成，父面板按钮改成与上下级面板一致的紧凑排列。

沿用已读个人插件开发技能及项目 AGENTS.md、合并对照清单、模块归属规则。
当前工作区包含上一轮未提交的 AutoBlend 整合，继续保留。
本轮只修改 New 文件及新增模块/测试/日志，不修改 Mixed 或 Pond 专属文件。

## 文件与行为

- `core/fab_material.py`：新增 `material.import_fab_visn` 和贴图发现、材质生成、图片加载函数。
  注册时不读场景或加载图片。原生文件夹选择器确认后执行导入。
- `core/__init__.py`：注册列表末尾追加 fab_material，既有顺序不变。
- `ui/bekkan/light_compose_panel.py`：同文件增加并注册 Fab/Megascans 材质导入子面板；
  父面板使用 `column(align=True)`，去除原中心约束灯光与探针之间的空白分隔。
- `tools/test_fab_material.py`、`tools/test_fab_material_ui.py`、
  `tools/test_fab_material_render.py`：隔离功能、原生交互与渲染验证。
- `开发计划/模块归属标注.md`：记录新模块、入口及紧凑布局；共同维护索引不变。

新猴头创建于 3D Cursor，自动生成 UV、平滑面和二级细分预览；不删除现有场景对象。
材质节点复用 `core/shader_tools.py::arrange_shader_tree()` 排列，无需编辑该模块。

贴图连线：

| 图 | 色彩空间 | 连接 |
|---|---|---|
| BaseColor | sRGB | Principled Base Color |
| Normal | Non-Color | Normal Map → Principled Normal |
| Displacement | Non-Color | Displacement Height → Material Output Displacement |
| Specular | Non-Color | Principled Specular IOR Level |
| Roughness | Non-Color | Principled Roughness |
| AO | Non-Color | 仅 Mapping → Vector，颜色/Alpha 输出不连接 |

材质 `displacement_method` 显式设为 `BUMP`（Bump Only），用户可自行切换至 BOTH。
Value 默认 1，浮点输出直接广播至 Mapping Scale 的 XYZ。

## 文件识别与错误处理

- 按磁盘中实际存在的文件识别，不采用 Fab JSON 中的 8K 原始资源 URI。
  示例实际为 4K，JSON 中最高分辨率及 maps 仍描述 8K；只将 JSON 的 name 用于命名。
- 支持常见大小写、BaseColor/Albedo/Diffuse、Normal GL/DX、Height、AO 等命名，
  JPG/PNG/EXR/TIFF/TGA；Bump、Cavity、Gloss 等不会加载。
- 同材质多分辨率默认选择最高分辨率，逐分辨率保持一整套，不混入其他分辨率或其他资产。
  支持仅含 2K/4K 等一级子目录的父目录；不深层递归扫描整个 Vault。
- 多材质文件夹或找不到 BaseColor 时取消；其他通道缺失则保留默认参数并报告缺少哪些图。
- 优先 OpenGL 法线；文件名明确为 DirectX 且无 GL 时，在 Normal Map 前翻转绿色通道。
- 重复导入会新建猴头和材质，可复用同路径且色彩空间已经正确的图片；
  不改其他材质已使用的图片数据。读取失败时清理本轮新增材质、图片/物体并恢复选择。

## 调试和验证

1. 实测 5.2.4 和 5.3：位移模式属性在 Material 上，枚举为 BUMP/DISPLACEMENT/BOTH，
   原 `material.cycles.displacement_method` 已不在这两个版本。
   Specular 对应新版 Principled 的 Specular IOR Level。
2. 功能测试两版本通过：真实 4K 六张图、2K 图组、大小写/分辨率、图片复用、
   AO 输出不连、Alpha 不连、Value/UV/Mapping、正常通道适配、缺图、损坏图、
   多材质检测、原有场景保留、节点不重叠、模式切换及启用/注销。
3. 原生 GUI 两版本通过：从 VIEW_3D 打开文件夹选择器，实际设置示例目录并确认，
   创建猴头与材质；一次撤销恢复对象/材质/图片数量，再重做恢复六张图。
   Fab 面板各记录 9 次成功绘制；紧凑父面板、Shader 节点均有实测截图。
4. 两版本 Cycles 256×256 真实材质渲染通过；猴头前景 11,447 像素，
   Value 从 1 调到 2 后分别有 7,374 / 7,372 个前景像素明显改变，证明缩放实际生效。
   渲染图已人工查看，贴图正常显示，无丢图粉色或空材质。
5. 语法检查、`git diff --check` 及构建资源检查通过；Fab 代码随三种完整包打入，
   工程分析独立包继续保持原范围。

所有测试使用独立 `BLENDER_USER_RESOURCES` 与 `--factory-startup`，没有重载、保存或
修改用户当前工程；输出位于被忽略的 `temp/`。本轮未 commit/push。
