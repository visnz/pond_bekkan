# 2026-08-03 别馆 UI 改造与快速模式切换

## 开发目标

作为别馆模式开发者，对 UI 层进行三项调整：

1. 删除插件设置面板中的 AddonManager 设置项，保留默认写死。
2. 别馆面板改为 8 个独立开关控制显示/隐藏。
3. 合体版在两模式 N 面板顶部增加快速模式切换入口。

## 涉及范围

- **共同维护模块**：`prefs.py`（唯一 AddonPreferences）、`ui/__init__.py`（模式分发）
- **别馆专属 UI**：`ui/bekkan/panels.py`、`ui/bekkan/snapshot_panel.py`、
  `ui/bekkan/analyzer_panel.py`、`ui/bekkan/addonmanager_panel.py`
- **新增文件**：`ui/bekkan/prefs.py`、`ui/mode_switcher.py`

## 实现细节

### 1. AddonManager 设置项移除

- `prefs.py` 删除 `_draw_addonmanager()` 方法，不再绘制使用须知、自动恢复、类别排除、收藏设置。
- `PondBekkanPreferences` 中仍保留 `auto_restore_on_new_file`、`excluded_categories`、
  `favorite_categories` 等字段，默认值写死，保证：
  - `core/addonmanager/` 核心运行不受影响；
  - 旧版用户偏好（独立版 `bekkan_visn`）仍可继承。

### 2. 别馆 8 个模块开关

新增 `ui/bekkan/prefs.py`：

```python
MODULES = [
    ("show_snapshot", "快照对比"),
    ("show_analyzer", "工程分析"),
    ("show_parents", "上下级"),
    ("show_stage", "搭建类"),
    ("show_texture", "贴图索引"),
    ("show_anime", "动画类"),
    ("show_render_preset", "渲染预设"),
    ("show_addonmanager", "颈椎拯救者"),
]
```

根 `prefs.py` 参考蛙灾做法，动态挂到 `PondBekkanPreferences.__annotations__` 上。
合体版/别馆独立版均会显示这 8 个开关（独立版下用户仍可关闭不用的模块）。

每个别馆面板增加 `poll = module_enabled("...")`：

- `VIEW3D_PT_parents_visn` → `show_parents`
- `VIEW3D_PT_stage_visn` → `show_stage`
- `VIEW3D_PT_texture_visn` → `show_texture`
- `VIEW3D_PT_anime_visn` → `show_anime`
- `VIEW3D_PT_render_preset_visn` → `show_render_preset`
- `SnapPanel` → `show_snapshot`
- `VIEW3D_PT_analyze_visn` → `show_analyzer`
- `ADDONMANAGER_PT_main` → `show_addonmanager`

### 3. 快速模式切换面板

新增 `ui/mode_switcher.py`：

- `POND_PT_mode_switcher`（类别「池塘」）
- `BEKKAN_PT_mode_switcher`（类别「别馆」）
- `POND_BEKKAN_OT_switch_mode` 操作符

仅在 `_build_mode.BUILD_MODE == "combined"` 时注册（`poll` 与 `register()` 双重检查）。
面板 `HIDE_HEADER`，显示当前模式标签 + 「切换 xxx」按钮。

`ui/__init__.py` 在 `_register_one` / `_unregister_one` 中同步注册/注销快速切换面板，
确保切换模式时不会残留旧模式面板。
