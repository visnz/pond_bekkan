# 模块归属标注

> 目的：让后续 AI 或个人开发者快速判断「这个文件/函数改不改、谁来改」。
> 基于 commit `a3283fa`（初版本合并预备）与当前工作区对比，结合代码注释、bl_idname 前缀、commit 重构历史综合判定。

## 判定图例

| 标签 | 含义 |
|---|---|
| `Pond` | 原蛙灾（Pond）项目代码，主要由蛙灾维护 |
| `Bekkan` | 原别馆（Bekkan）项目代码，主要由桶桶维护 |
| `Mixed` | 两边代码合并共存，或已重写为共同资产，修改需双方知情 |
| `New` | 合并后新增，无原始归属 |

## 共同维护清单（Mixed 模块）

这些文件同时包含 Pond 与 Bekkan 的代码，或已被重写为双方共用的资产。**任何修改都需要同步更新本清单**，并在开发计划中记录决策。

| 文件 | 涉及双方内容 | 修改前必读 |
|---|---|---|
| `core/hierarchy.py` | Pond 6 op + Bekkan 7 op + 共享助手 | 合并对照清单第 4 节：两边语义不同，勿随意合并/删除 |
| `core/stage.py` | Bekkan 摄像机组/开文件夹 + Pond 约束灯光/简洁机组 | 两种摄像机组设计并行，改动需明确影响哪套 |
| `core/snapshot.py` | Bekkan 核心 + Pond 删除/导出/清理逻辑 | 已重写为共同核心，改 GPU/交互前参考调试报告 |
| `__init__.py` | 注册中心 | 改注册顺序会影响模式切换与 addonmanager 面板恢复 |
| `prefs.py` | 合并后唯一 AddonPreferences | 同时影响模式开关、模块开关、颈椎拯救者设置 |
| `ui/__init__.py` | 模式分发 | 改切换逻辑需实测合体版与独立版 |
| `ui/bekkan/__init__.py` | 别馆注册/注销 | 内含 addonmanager 注册与面板恢复顺序 |
