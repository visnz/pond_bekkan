# 插件调试：一键重载

## 需求及最终位置

桶桶要求一键重载插件，随后指定单独的「插件调试」面板，且不要改偏好设置。最终仅在别馆 N 面板添加入口。最初放入 prefs.py 的逻辑已全部移出，该文件与 HEAD 无差异。

## 修改

- 新建 `core/debug.py`：重载操作符及延迟回调。
- `core/__init__.py` 增加 debug 注册，沿用现有注册与反向注销流程，池塘 UI 不增加入口。
- `ui/bekkan/panels.py` 增加独立「插件调试」面板，内含「重载插件」。
- 更新模块归属表。

点击后 0.2 秒执行，以避开当前操作符/面板绘制。先注销插件，再移除本插件的 Python 模块缓存并从磁盘重新导入；保留插件启用偏好、模式与模块开关，刷新界面。保留常驻启用标志。注销失败则停止继续重载；失败打印回溯并显示错误提示。

重载等同重新启用插件，快照等临时状态会清空。不会保存用户工程或偏好设置。新增代码本身首次仍需手动重新加载后，按钮才能出现。

## 验证

Blender 5.2.3 独立后台连续两次完整注销/导入/注册通过，确认模块身份变化、模式与模块开关保留、功能操作符和独立调试面板存在。

初次测试 addon_utils 默认刷新还触发了全局扩展缓存维护，出现权限日志；最终调用设置 refresh_handled=True，限定本次重载本插件，复测不再出现扩展维护日志。剩余 SnapPanel 类名警告为既有命名。

后台测试验证同步重载主体，按钮定时器及前台点击待用户实测。没有重载现场 Blender，未提交或推送。
