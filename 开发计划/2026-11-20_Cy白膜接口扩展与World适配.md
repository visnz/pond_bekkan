# Cy 白膜接口扩展与 World 适配

## 目标与范围

按用户要求给物体 Cy 白膜组增加 Normal 输入、纯白 Transparent BSDF 输出，
以及接到 Diffuse Color 的 0–1 Value 输入（新组默认 0.8）。
补充 World 双引擎适配；用户确认 Cycles 使用独立 Background，灰度 0.8、强度 1。

已按个人插件开发技能和项目规范检查合并清单、模块归属。
只修改 Bekkan 专属 core/texture.py；原面板和操作器已注册，无需修改 Mixed 或池塘 UI。
同步模块归属说明，无共同维护清单新增项。本轮未重载或修改用户当前工程。

## 修改文件与行为

- core/texture.py：_extend_cycles_clay_group 原位升级、_clay_group_users 查既有引用，
  调整 _cycles_clay_group 与 _is_default_cycles_clay；新增 adapt_cycles_worlds、
  _is_default_cycles_world；既有 material.cycles_clay_visn 同时处理材质和 World。
- tools/test_cycles_clay.py：隔离结构、旧组/自定义值、重复适配、World 及渲染验证。
- tools/test_cycles_clay_ui.py：真实侧栏、节点界面、单步撤销/重做。
- 本日志与模块归属标注；重新生成四种 zip。

共享组保留原 BSDF 输出接口标识，追加 Transparent BSDF，颜色 (1,1,1,1)。
Normal 为隐藏数值的 Vector 接口，连接 Diffuse Normal；不接线时渲染使用模型自然法线。
Value 为 Float，范围 0–1；新组默认 0.8，既有用户自定义灰度保留并初始化到原组实例。
原有 Color/Normal 连线、非灰度颜色保留；主输出已改为其他着色器的旧组不强改结构。
修改过 Value、接入 Normal 或使用透明输出会被识别为自定义白膜。
组以版本标记避免重复增设；只在用户执行适配时升级，不在注册期间读写场景数据。

World 原 All 输出改为 EEVEE，保持其天空/HDRI 和其他连接。
缺少 Cycles 输出则补上；完全空的 Cycles 输出接独立 Background，灰度 0.8、强度 1。
已有 Surface/Volume 连接、仅 Cycles 的 World 及不可编辑数据保留。
重复运行不增添节点，不重置已调整的强度。报告分别列出材质和 World 的计数。

## 调试与验证

1. 运行时探测发现 Shader 接口的 default_input 动态枚举仅允许 VALUE，
   静态 RNA 虽列 NORMAL，但不能赋值。改用原生 Normal 插座复制和 hide_value；
   Cycles 实测确认未接线与旧白膜画面完全一致，不引入额外法线替代节点。
2. 新增接口默认值不依赖旧组用户自动同步，显式初始化本次新 Value 插座。
3. GUI 脚本调用操作器需传原生 undo 参数 True，才能模拟真实按钮的撤销记录。
   首轮测试回到了夹具建立之前，修正测试调用后两个版本均单步撤销/重做通过。

Blender 5.2.4 LTS、5.3.0 后台均通过：新组、旧共享组升级、外层 BSDF 标识/连接保留、
0–1 范围、默认灰度、Normal/透明连线、重复适配、自定义灰度/颜色/连线保护、同名无关组，
以及 World 的天空保留、已有 Cycles/Volume/仅 Cycles 跳过和自定义强度保护。

两版本 Cycles 96×96 渲染通过：升级前后最大像素差 0.0；Value 0.4 / 0.8 亮度比例 0.5；
接入倾斜 Normal 明显改变表面；Transparent 输出的 alpha 为 0；Cycles 世界背景线性 RGB 为 0.8。

两版本真实 GUI 均通过：灯光合成入口绘制、共享组接口/外层 Value 显示、World 双输出、
在 World 编辑上下文重复调用，以及材质/组/World 同时一次撤销和重做。截图已检查。
测试使用独立 factory-startup 实例及临时配置；未保存、重载用户工程。
结果在 temp/clay52.log、temp/clay53.log、temp/clay*-check.log、temp/clay-ui52/、temp/clay-ui53/。

静态语法及差异格式检查通过，四种 zip 已生成并校验完整性与最新 texture.py 一致。
