# 2026-08-07 快照未捕捉摄像机遮罩（Passepartout）修复

## 目标

用户反馈：Ctrl+Alt+右键拍摄快照时，如果在摄像机数据里开了「遮罩」
（`camera.data.show_passepartout` + `passepartout_alpha`，把取景框以外区域压黑），
实际视口能看到黑色遮罩，但拍出来的快照没有——框外内容跟框内一样清晰，等于遮罩被
「穿透」拍到了。

## 根因

`core/snapshot.py::_capture_offscreen()` 用 `GPUOffScreen.draw_view3d(...)` 离屏
重画场景来拍快照。这个底层 API 只重演 3D 场景内容本身，不包含摄像机遮罩这类
「取景引导」2D 叠加层——遮罩是交互视口自己另外画的一层，不会随 `draw_view3d()`
的离屏重画一起出现。用户描述的现象（遮罩完全不在快照里）正好印证了这点。

## 改动（`core/snapshot.py`，Mixed 共同维护文件）

跨边界说明：改的函数是 `_capture_offscreen` + 新增 `_passepartout_mask` helper；
原归属 Mixed（蛙灾/桶桶共同维护）；理由是修复快照拍摄本身的 bug，`core/` 两侧 UI
共用；`object.take_snapshot` 是 core 常驻注册的操作符，两个模式共用同一份实现，
改完两侧行为同步变化，只有摄像机遮罩开启时才有可见差异，其余场景不受影响；归属
不变，不需要更新 `模块归属标注.md`。

1. 顶部新增 import：`from bpy_extras.view3d_utils import location_3d_to_region_2d`。
2. 新增 `_passepartout_mask(context, space, region, rv3d)`：只在
   `rv3d.view_perspective == 'CAMERA'` 且摄像机开着 `show_passepartout` 时才算，
   用 `camera.data.view_frame(scene=scene)` 拿本地空间 4 角点，`matrix_world`
   变换到世界坐标，`location_3d_to_region_2d` 投影到 region 像素坐标，取
   min/max 得到取景框矩形（自动适配 letterbox/pillarbox），连同
   `passepartout_alpha` 一起返回；任何一步失败（非摄像机视角、摄像机没遮罩、
   投影失败）都返回 `None`，不遮罩、维持原样。
3. `_capture_offscreen` 里，在 `buf = off.texture_color.read()` 之后、构造
   `GPUTexture` 之前插入后处理：把 FLOAT buffer 转成 `(h, w, 4)` 的 numpy 数组，
   取景框矩形外的像素 RGB 三通道乘 `(1 - alpha)`（跟黑色做直接的 alpha 混合，
   alpha 通道不动），再用 `gpu.types.Buffer("FLOAT", w*h*4, arr)` 包回去喂给
   `GPUTexture`——这个「numpy 数组直接喂 `gpu.types.Buffer`」的构造方式在
   `tools/test_snapshot.py::test_gputexture` 里已经验证过能用，不是新的未验证
   API 用法。

区域行顺序：GPUOffScreen 读出来的第 0 行对应 region 里 y=0（跟
`location_3d_to_region_2d`/`mouse_region_y` 的 y=0-在底部惯例、以及 OpenGL
`glReadPixels` 的行序一致），矩形切片不用额外翻转。

## 已知限制

- 只做矩形遮罩，不还原 Blender 原生遮罩边缘的抗锯齿，边界可能有 1px 级取整误差，
  纯外观细节。
- 非摄像机视角（透视图/正交图）下 `view_perspective != 'CAMERA'` 直接跳过，
  零开销，行为跟改动前一致。

## 已知风险 / 待验证

未跑 GUI 实测，只过了 `python -m compileall -q .`。需要 F8 重载后核对：

- 摄像机视角下 `show_passepartout=True` + `passepartout_alpha=1.0`（用户当前
  设置，对照 `core/hierarchy.py` 对焦空物体功能同款设置），拍摄后快照取景框外
  应为纯黑，框内内容与实景一致，没有被误裁切。
- `passepartout_alpha` 用默认 0.5（半透明）时，框外应变暗但非纯黑，混合比例
  跟视口里的半透明遮罩程度一致。
- 摄像机取景框宽高比跟视口窗口不一致（不同 Sensor Fit）时，letterbox/pillarbox
  两种情况遮罩矩形都能正确贴合取景框。
- 非摄像机视角（透视图）拍摄，行为跟改动前完全一样，不受影响。
- 关掉 `show_passepartout` 后再拍，不会误加遮罩。

## 测试结果

`python -m compileall -q .` 无报错。GUI 实测留给用户在 Blender 里验证。
