# 所选物体到上级：世界中心与层级修复

## 目标与授权范围

用户反馈三个已有父级的对象执行「所选物体 到上级」后，新空物体的中心偏移。希望同父级时在原父级下面插入新组；不同父级时放在最外层原父级下，同时保持世界位置和子树。

修改前已阅读 AGENTS.md、合并对照清单和个人插件开发规范，说明 `core/hierarchy.py` 属于 Mixed，并取得当前用户明确同意：「同意，按这个范围修复」。批准范围为 Bekkan `P2E.execute()` 及其新增专用辅助函数，以所选原点的世界坐标均值计算中心，同父级保留原直接父级，不同父级取最外层原父级，不相关根并列时采用活跃对象所属分支。

Pond 的六个操作器、共享 `centro()` / `centro_global()`、其他 Bekkan 分组/动画迁移工具、两侧 UI、注册顺序不改。保留工作区之前尚未提交的 Setup 天空与 World Sun/Sky 同步等功能。

## 修改文件与实现

- `core/hierarchy.py`：仅新增 Matrix 导入、P2E 专用 `_p2e_roots()`、`_p2e_group_parent()`、`_p2e_parent_transform()`，修改 `P2E.execute()` 与按钮说明。先更新视图层、捕获所选世界原点均值和原层级/逆矩阵/集合，跟踪原子树世界矩阵；同选父子只重新挂接最外层选中根，避免拆子树或制造循环。
- 新组通过数据 API 创建，挂目标原父级并设置其逆矩阵，组原点为世界中心。原对象的父级空间影响完整转移到新父级逆矩阵，保留原局部通道及旋转/非均匀缩放产生的剪切；普通对象父级直接取原父世界矩阵乘原逆矩阵，骨骼/顶点父级从世界矩阵和 basis 反算。单选保持原 Euler 取值行为。
- 保留既有集合规则：所选对象与新组进入活跃对象所属集合，成功后只选中并激活新组。不可编辑或不可逆矩阵提前取消；更新后核对组矩阵与整棵子树世界矩阵，变换异常时恢复原父级、类型、骨骼名、逆矩阵及集合，删除本次新组。检查使用相对/绝对 `1e-5` 浮点容差。
- `tools/test_parent_to_empty.py`：隔离后台回归，验证世界中心、父级策略、子树、局部通道、集合、约束、失败恢复，以及两个既有 Pond 操作器。
- `tools/test_parent_to_empty_ui.py`：隔离原生图形实例，注册完整插件，正常选中三个带父级逆矩阵的对象，调用真实 P2E `INVOKE_DEFAULT`，验证组中心与一次撤销/重做。
- `开发计划/模块归属标注.md`：同步 P2E/专用助手明细和共同维护清单，本文件保留 Mixed 归属，不增减共同维护模块索引。

## 调试过程

用世界矩阵直接赋值会分解带旋转/非均匀缩放的剪切，因此最终只转移父级有效变换到逆矩阵，不重写原 basis。

驱动失败恢复测试最初未启用隔离进程的 Python 表达式执行，测试驱动 `self.parent.location.x` 被 Blender 限制，取消断言失败。只在该 factory-startup 测试进程临时启用表达式后，驱动正常生效并触发预期回退，没有保存或改变用户偏好。

增加负缩放和 delta 变换后，发现失败恢复路径重写保存的 `matrix_basis` 会重新分解这些通道，导致精确还原断言失败。已移除此处赋值：操作原本只修改父级和逆矩阵，恢复这些关系后驱动重新求值即可，未被主动改写的局部通道保持原样。两版包含该情况的最终测试均通过。

## 边界与 TODO

本操作仍以选中对象原点均值为中心；同时选中父子时，两者原点都计入均值，挂接仅作用于最外层选中根。父级分支策略按本轮授权执行，不自动寻找最近公共祖先。

只保证当前求值状态，不做跨帧动画迁移或烘焙。骨骼/顶点父级测试覆盖普通父级，带复杂约束的组合以结果检查决定是否取消；无法保持变换时提示并回退，不强行改写约束/驱动。

当前工程未重载、修改或保存；没有 commit/push。用户重载插件后新按钮逻辑生效。本轮无新增必做 TODO。
