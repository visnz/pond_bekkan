# 2026-10-20 新增快捷键：Ctrl+` 快速呼出池塘/别馆 N 面板

## 目标

用户需求：按一个快捷键，在当前 3D Viewport 的 N 栏快速切换/呼出本插件的
面板页，不用手动点 N 栏标签找「池塘」或「别馆」。

## 跨边界说明（协作规则要求，改动的是 Mixed 共同维护文件 `prefs.py`）

1. **改哪个文件/函数**：`prefs.py` 新增 `WM_OT_toggle_pond_bekkan_sidebar`
   operator（`wm.toggle_pond_bekkan_sidebar_visn`），复用文件里已有的
   `_switch_sidebar_category(mode)` 辅助函数（原本只给 `_on_mode_update`
   内部调用）；`register()`/`unregister()` 追加这个 operator 的注册和一条
   `Ctrl+\`` 快捷键绑定/解绑。
2. **原归属**：`prefs.py` 是 Mixed 共同维护文件（唯一 AddonPreferences）。
3. **理由**：用户直接需求——快捷键呼出 N 面板。
4. **是否影响另一模式**：不影响任何已有逻辑。新增的 operator 只读
   `_build_mode.BUILD_MODE` 和（合体版下）`prefs.mode` 来决定切到哪个
   category，不修改任何已有字段/行为；三个版本（合体/蛙灾独立/别馆独立）
   都能用，各自切到自己唯一的分类。
5. **是否需要更新归属标注**：`模块归属标注.md` 里 `prefs.py` 没有函数级
   明细表（只在共同维护索引表里登记整个文件），本日志即留档记录，不用
   额外改标注文件。

## 改动

- `prefs.py`：
  - 新增 `WM_OT_toggle_pond_bekkan_sidebar`（`wm.toggle_pond_bekkan_sidebar_visn`）：
    - 独立版（`BUILD_MODE in ("pond","bekkan")`）直接按固定分类切；
    - 合体版读 `context.preferences.addons[pkg].preferences.mode` 决定切
      「池塘」还是「别馆」。
    - 调用已有的 `_switch_sidebar_category(mode)`：确保 `show_region_ui =
      True`（强制打开 N 栏，不做"已打开就收起"的 toggle 行为——按用户要求，
      已经在目标页时保持显示，不收起）+ `region.active_panel_category =
      目标分类`。
  - `register()`：在原有基础上追加
    `wm.keyconfigs.addon.keymaps.new(name="3D View", space_type="VIEW_3D")`
    + `km.keymap_items.new("wm.toggle_pond_bekkan_sidebar_visn",
    "ACCENT_GRAVE", "PRESS", ctrl=True)`（反引号键，Blender 枚举标识符是
    `ACCENT_GRAVE`）。写法参照 `core/snapshot.py` 已有的 keymap 注册/注销
    模式（用 `_addon_keymaps` 列表记住 `(km, kmi)` 方便精确卸载，比
    `core/snapshot.py` 按 idname 遍历删除更不容易误删其他插件在同一个
    "3D View" keymap 下注册的项）。
  - `unregister()`：对称地移除快捷键绑定。

## 调试与测试过程

用户当前 Blender（5.2.2 LTS）已通过 MCP for Blender 连接，直接在真实会话
里用 `execute_blender_code` 验证：

1. `python -m compileall -q prefs.py`：无报错。
2. `bpy.ops.script.reload()` 热重载后确认
   `wm.toggle_pond_bekkan_sidebar_visn` 已注册。
3. 读 `wm.keyconfigs.addon.keymaps["3D View"]` 里的 keymap item，确认
   `type="ACCENT_GRAVE"`、`ctrl=True`、`alt=False`、`shift=False`，与预期
   绑定一致。
4. 把 N 栏切到别的分类（`Tool`）并隐藏（`show_region_ui=False`），调用
   operator 后确认：`show_region_ui` 变 `True`，`active_panel_category`
   变回「别馆」（当前合体版 `prefs.mode=BEKKAN`）。
5. 已经在「别馆」页且可见的状态下再调用一次，确认页面保持不变、不收起
   （符合用户要求的"保持显示"行为）。
6. 额外发现一个**已有架构的时序特性**（非本次改动引入的问题）：
   `prefs.mode` 的 UI 重建是通过 `bpy.app.timers.register(..., first_interval=0.01)`
   延迟到下一帧执行的（`_on_mode_update`，原有代码）。如果脚本里紧挨着
   `prefs.mode = "POND"` 之后立刻同步调用快捷键 operator，会读到切换前的
   旧分类文字（因为 `ui.apply_mode()` 还没在那个延迟的 timer 里真正跑完）。
   真实使用场景里用户是点按钮切模式、过了正常的帧间隔才按快捷键，不会撞
   上这个窗口，所以未做改动；记录在此供后续排查类似问题时参考。

## 测试结果

- 静态检查通过。
- 真实 Blender 5.2.2 环境端到端测试通过：快捷键注册正确、隐藏→呼出、
  已显示时保持不收起，均符合预期。
- 未做的测试：真实键盘按下 `Ctrl+\`` 触发的手感（这次全程用
  `execute_blender_code` 直接调用 operator 模拟，没有发送真实按键事件），
  建议用户下次打开 Blender 时实际按一下确认。
