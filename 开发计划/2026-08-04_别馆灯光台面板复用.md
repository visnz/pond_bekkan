# 2026-08-04 · 别馆侧新增「灯光台」面板（复用蛙灾 Pond 面板类，正文零副本）

## 1. 目标与范围

桶桶要在别馆模式加一个「灯光台」功能。经确认走**引用蛙灾一整块**的路线：
逻辑（op / 属性）在 `core/lightdesk.py` 常驻（core 注册表，两模式都注册），
别馆侧只做皮肤壳，**子类化 `ui/pond/panels/lightdesk.py` 的 `POND_PT_lightdesk`**，
正文零副本（沿用 devPlan 里给蛙灾侧 analyzer 预留的「方案 A：复用面板类」同套路）。

用户拍板：**复用 Pond 的 `show_lightdesk` 开关**（不新加开关）+ **顶层独立面板**。

## 2. 改动内容

### 新增 `ui/bekkan/lightdesk_panel.py`（别馆，New）

```python
from ..pond.panels.lightdesk import POND_PT_lightdesk

class BEKKAN_PT_lightdesk(POND_PT_lightdesk):
    bl_idname = "BEKKAN_PT_lightdesk"
    bl_label = "灯光台"
    bl_category = "别馆"
    bl_parent_id = ""   # 顶层独立面板；Blender 5.2 的 bl_parent_id 不支持 None，空串=无父
```
- `poll` 继承基类的 `module_enabled("show_lightdesk")` —— 与蛙灾共用根 prefs 上同一个
  `BoolProperty`（一处关两处都关），零额外开关代码。
- 灯光组 / solo / 视口隐藏全部共用 `core/lightdesk.py` 同一份数据与 op
  （`bpy.ops.pond.ld_*`），两套皮肤操作同一套灯。

### `ui/bekkan/__init__.py`（Mixed，按 AGENTS.md §2 已向当前用户说明影响范围并获同意）

- import 加 `lightdesk_panel`；`register()` 在 `analyzer_panel` 之后注册；
  `unregister()` 按倒序注销。

### `开发计划/模块归属标注.md`

- ui 表新增 `ui/bekkan/lightdesk_panel.py`（New，引用 Pond）。

## 3. 协作归属说明

- `core/lightdesk.py`、`ui/pond/panels/lightdesk.py` 是 **Pond 专属**，本次**只读引用、
  未改其内容**（符合项目「跨归属只读 import 可接受」先例）。按惯例建议让蛙灾知悉一声。
- `ui/bekkan/__init__.py` 是 **Mixed**，本次只加一行面板注册，不改变其 Mixed 归属。
- 新文件 `ui/bekkan/lightdesk_panel.py` 归别馆（桶桶）。

## 4. 验证

- `python -m compileall -q .` → exit 0。
- `python build.py` → 4 个 zip 正常产出；抽查三个非 analyzer 变体：
  均含 `ui/bekkan/lightdesk_panel.py` + `ui/pond/panels/lightdesk.py` + `core/lightdesk.py`。
- Blender 后台实测（`--background --factory-startup`，整仓注册）：
  - 单独注册 `BEKKAN_PT_lightdesk`：`bl_category='别馆'`、`bl_parent_id=''`、注册成功、
    `poll(context)=True`（继承默认）、draw 不崩。
  - 整仓 `register()` → `apply_mode('BEKKAN')`：`BEKKAN_PT_lightdesk` 注册、
    `POND_PT_lightdesk` 注销、`poll=True`。
  - `apply_mode('POND')` 切回：`POND_PT_lightdesk` 注册、`BEKKAN_PT_lightdesk` 注销
    （两模式 UI 互斥，不会同屏出现两个灯光台）。
  - `unregister()` 干净。唯一告警 `'SnapPanel' does not contain '_PT_'` 是既有问题，
    与本改动无关。

## 5. GUI 实测留给用户

1. F8 重载 → 切别馆模式 → 确认「别馆」分类出现「灯光台」顶层面板。
2. 建组 / 分配选中灯 / solo 单灯与整组 / 退出 solo / 视口隐藏 / 解散组，逐项与蛙灾侧行为一致。
3. 偏好设置里关掉 Pond 的「灯光台」开关 → 别馆侧该面板也消失（共用一个总开关）。
4. 切回蛙灾模式确认原灯光台面板不受影响。
