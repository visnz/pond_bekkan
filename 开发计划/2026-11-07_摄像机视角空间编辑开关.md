# 摄像机视角空间编辑开关

## 目标与范围

桶桶需要在别馆插件栏一键进入/退出摄像机视角空间编辑：记录图示的变换坐标系、变换枢轴点及 3D Cursor 位置；开启时 Cursor 移到当前场景活动摄像机的世界位置，坐标系切 View、枢轴点切 3D Cursor；关闭时恢复。

`core/stage.py` 是 Mixed 共同维护文件，新增独立 `StageToggleCameraSpace`、状态/恢复辅助函数，并在既有注销入口调用恢复；`ui/bekkan/panels.py` 为 Bekkan 专属，只在「搭建类」加入状态按钮。Pond UI 无新入口。更新共同维护清单。

## 行为与实现

通过 `scene.transform_orientation_slots[0].type`、`scene.tool_settings.transform_pivot_point`、`scene.cursor.location` 读写图中三个设置。活动摄像机取 `scene.camera`，位置取 `camera.matrix_world.translation`。状态按 scene 指针存于运行时字典，按钮文字随当前状态变化。未指定摄像机时仅提示，不改变设置；禁用/重载插件时注销入口恢复尚未关闭的临时设置。操作不参与 Blender Undo 历史，退出应再次点开关。

## 验证

Blender 5.2.3 独立后台通过 3D View context override 测试：从 LOCAL/ACTIVE_ELEMENT/Cursor(3,4,5) 开启后变为 VIEW/CURSOR/摄像机世界位置(10,20,30)，关闭后全部恢复；无活动摄像机时返回取消且设置不变。前台 UI 点击待用户实测。没有修改或保存用户当前工程。

## 2026-11-07 用户实测后的修复

用户反馈关闭后坐标系和枢轴点未恢复，且按钮状态不明显。只读检查当前 Blender 的 `F:\小图练习3\义妹生活.blend`：Scene.001 仍为 VIEW / CURSOR，原实现的模块级 `_camera_space_states` 已是空字典。原备份随模块热重载丢失，无法可靠推断本次操作前的原始值，因此未擅自改动用户现场。

改为将恢复快照按 `scene.session_uid` 存入 WindowManager 自定义属性（JSON），模块重新导入后仍可读取；关闭与注销时删除快照。开启时按钮红色高亮并显示按下状态，旁边显示当前模式；若正处于 View/Cursor 却无恢复记录，提示这一事实。Blender 5.2.3 隔离测试验证模块 `importlib.reload` 后快照仍在，随后关闭可恢复 LOCAL/ACTIVE_ELEMENT/Cursor(3,4,5)；再次开启仍可读取状态。初次测试脚本的类注销查找写法错误，修正后通过；功能断言此前已通过。验证 `UILayout.operator(depress=...)` 与 `row.alert` 在 5.2.3 可用。
