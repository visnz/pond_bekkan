# Shader 白膜入口迁移与按钮短名

## 目标与范围

按用户要求，将「白膜适配」「取消白膜适配」从灯光合成移到 Shader 脚本，
并将五个材质按钮文字改为：
导入Fab材质、整理、图片转Non-Color、修复全局法线Non-Color、选中无关输出节点。

已按个人插件维护技能及项目规范核对边界。
本轮只改 New/Bekkan 的现有 UI，不改 Mixed 注册中心或池塘 UI。
保留此前白膜接口、World 适配与取消操作尚未提交的实现，也保留 Shader 中已有 Foto 脚本。

## 修改与行为

- ui/bekkan/shader_panel.py：五个按钮使用指定 text；追加 Cy白膜适配、取消白膜适配。
  poll 扩展为材质和 World 的 Shader 编辑器；World 模式只显示两个白膜操作。
  材质专用操作及 Foto 仍只在材质模式绘制。
- ui/bekkan/light_compose_panel.py：移除两个白膜按钮，更新入口注释。
- tools/test_cycles_clay_ui.py：从 Shader 编辑器执行原生适配/取消与撤销重做，
  验证材质与 World 的面板。
- tools/test_cancel_cycles_clay.py：核对新入口相邻、灯光合成不再显示入口。
- tools/test_fab_material.py：核对五个文字、World 两入口及原功能的编辑器限制。
- 本日志与模块归属说明。

仅改侧栏显示名称；操作器 idname、搜索名称、算法及提示范围保持原样。
继续沿用原面板注册，未增加新面板。

## 验证与调试

Blender 5.2.4 LTS / 5.3.0 后台及真实 GUI 通过：

- 五个按钮文字精确对应用户要求，两个白膜入口紧接其后。
- 灯光合成无白膜入口；Shader 材质和 World 模式均能使用适配/取消。
- World 面板不绘制材质专用及 Foto 操作，Fab 操作器在 World 中不可调用。
- 原 Fab 识别、导入与失败回退、全工程法线修复、模式切换/注册通过。
- Shader 上下文的白膜升级、World 适配、取消、重复调用和原生一次撤销/重做通过。
- 实际界面无 draw 异常；材质和 World 截图已检查。

后台测试切换 shader_type 后原 path 仍指向材质，造成 World poll 首轮未通过；
更新夹具为明确的 World path 后通过，实际 GUI 切换正常。
扩展旧布局记录器以支持既有 Foto UI 的 row/label/预设属性，不调用外部图片处理。

测试使用独立 factory-startup/临时配置，不修改、重载或保存用户当前工程。
日志在 temp/shader-panel52.log、temp/shader-panel53.log、
temp/cancel-clay-panel52.log、temp/cancel-clay-panel53.log；
GUI 结果/截图在 temp/clay-ui52/、temp/clay-ui53/。

静态语法和差异格式检查通过，四种 zip 已重新生成并验证完整性和 UI 源码一致。
