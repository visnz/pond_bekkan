# Setup 开启时间轴帧范围限制

## 目标与范围

按用户截图，将 Timeline → Playback → Limit to Frame Range 加入一键工作区 setup。
遵循已读插件开发技能、项目 AGENTS.md 与合并对照清单。
只修改 New 的 `core/workspace_setup.py`、既有 setup 测试与模块归属记录，不涉及 Mixed 文件。

## 修改

- `_SETTING_NAMES` 增加「限制到帧范围」的中文报告名称，归入现有「通用」分类。
- `render_settings_plan()` 增加 `(scene, 'lock_frame_selection_to_range', True)`。
- 原值关闭时报告「关闭 → 开启」，原值开启时进入「原本一致」；沿用现有异常恢复及撤销机制。
- `tools/test_workspace_setup.py` 扩展实际设置比较与故障恢复检查，重复 setup 一致项计数由 28 更新为 29。
- `tools/test_workspace_setup_ui.py` 将该开关加入场景快照，验证完整 setup 的一次撤销/重做。
- `开发计划/模块归属标注.md` 记录新设置；既有场景保留/补齐规则不变。

## 调试与验证

检查 Blender 5.2 与 5.3 原生 `space_time.py`，截图开关对应的属性均为
`Scene.lock_frame_selection_to_range`，属于场景级设置，不需要逐窗口修改。

Blender 5.2.4 隔离后台完整 setup 回归通过：原始/空/已有场景、重复执行、
改动报告精确分类、缺失资源补齐及故障恢复。
新增开关验证包括关闭变开启、报告中文值及失败时恢复关闭。
GUI 首轮发现报告窗口使用固定分类顺序，不支持新增「时间轴」分类；
将本项归入现有「通用」，避免扩大 UI 修改范围。GUI 复测通过，
一次撤销/重做检查包含该开关，三种报告页签与报告重新打开均正常。

测试使用独立 `BLENDER_USER_RESOURCES` 和 factory-startup，不修改用户当前工程。
本轮不 commit/push；无待完成功能。
