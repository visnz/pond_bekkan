# 2026-08-04 · analyzer 面板双副本去重 + 独立版构建修正

## 1. 目标与范围

消灭 analyzer 面板的人肉双副本，改为 build 时从合并版唯一源**生成**独立版面板。
顺带修掉独立版的一个**潜在 import 崩溃 bug**（经实证复现）。

**不碰**：`core/analyzer/` 全部逻辑层、合并版 `ui/bekkan/analyzer_panel.py` 正文、
别馆侧注册流程。运行时行为零变化。

## 2. 起因：发现的两个问题

### 2.1 面板双副本漂移风险
合并版 [ui/bekkan/analyzer_panel.py](../ui/bekkan/analyzer_panel.py) 与
独立版 [build_assets/analyzer/ui/analyzer_panel.py](../build_assets/analyzer/ui/analyzer_panel.py)
正文（draw_item / filter_items / _draw_detail / _draw_fix_buttons / _wrap / _icon）完全相同，
只有头注释、`bl_category`、`poll` 三处不同。以后改 UI 要手改两份，漏一份即独立版功能缺失且无测试覆盖。

### 2.2 独立版潜在 import 崩溃（实证复现）
独立版面板第 6 行 `from ...core.analyzer import model, state` 用 **3 个点**。
但独立版打包后是 `analyzer_tool/ui/analyzer_panel.py`，`ui/` 还是**命名空间包**
（无 `__init__.py`，与 `build_assets/analyzer/ui/` 实际结构一致），位于包根下第 2 层。
Python 相对导入规则：N 个点 = 向上跳 N 层。3 个点在 depth=2 上会跳过包根。

**实证**（用真实 `analyzer_tool` 包结构 + 命名空间 `ui/` 测）：

| 导入写法 | depth=2 命名空间 ui | 结果 |
|---|---|---|
| `from ...core.analyzer import hi`（3 点）| `ImportError: attempted relative import beyond top-level package` | ❌ |
| `from ..core.analyzer import hi`（2 点）| 成功 | ✅ |

对照合并版 `pond_bekkan/ui/bekkan/analyzer_panel.py`（depth=3，有 `__init__.py`）
3 点导入正确 ✅ —— 源不动，只由 build 生成时改写为 2 点。

> 结论：当前独立版面板一旦加载就会抛 ImportError，面板注册失败、工程分析页空白。
> 这 bug 之前没暴露，可能因为独立版还没真正发出去过 / 测过加载。

## 3. 方案：build 时生成独立版面板

### 3.1 改动点
1. **删** `build_assets/analyzer/ui/analyzer_panel.py`（人肉副本不再保留）。
   `build_assets/analyzer/ui/` 若空则一并删。
2. **改 build.py**：analyzer 变体打包时，不再从 `build_assets/analyzer/ui/` 取面板，
   而是读合并版源 `ui/bekkan/analyzer_panel.py`，做**基于锚点的确定性文本改写**后
   写进 zip 的 `analyzer_tool/ui/analyzer_panel.py`。
3. **改 build.py**：`build_assets/analyzer/` 只剩 `__init__.py` + `prefs.py` 两个
   真正独立版专属根文件。

### 3.2 文本改写规则（锚点替换，非正则）
源 [ui/bekkan/analyzer_panel.py](../ui/bekkan/analyzer_panel.py) 确定文本：
- 头注释两行 → 独立版说明
- `from .prefs import module_enabled` 整行 → 删（独立版无模块开关）
- `bl_category = '别馆'` → `bl_category = '工程分析'`
- `bl_options = {'DEFAULT_CLOSED'}` → 删（独立版默认展开，整个面板就是为它服务）
- `poll` 类方法整块（`@classmethod` + `def poll` + return 行）→ 删
- `from ...core.analyzer import model, state` → `from ..core.analyzer import model, state`（修 import 深度）

### 3.3 不碰
- `core/analyzer/` 整个纯逻辑层零改动
- 合并版面板正文（唯一源）不动
- 别馆侧注册流程 `ui/bekkan/__init__.py` 不动
