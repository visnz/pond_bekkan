# 几何节点入口封装与 Panel 同步

## 目标与范围

新增 Geometry Nodes 专用「别馆 → 几何节点脚本」侧边栏，首个脚本「封装当前节点入口」。
将当前编辑层选中节点组的未连接输入，暴露到当前节点树接口，并统一连接一个独立 Group Input。
按用户补充，同步原接口中的 Panel 分组。

2026-11-19 用户明确批准 `ui/bekkan/__init__.py`（Mixed）追加面板导入、注册与反向注销。
本轮保持池塘 UI 和 addonmanager 面板恢复顺序，不修改其他 Mixed 文件。
`模块归属标注.md` 已登记新文件，并更新共同维护清单中的别馆注册入口记录。

## 修改文件与实现

- `core/geometry_tools.py`（New）：当前 Geometry 编辑层查询、输入封装、接口/Panel 复制、共享用户参数初始化、失败回退及操作器。
- `ui/bekkan/geometry_panel.py`（New）：仅 Geometry Nodes 显示的脚本容器。
- `core/__init__.py`（New）：末尾追加逻辑模块，原注册顺序不变。
- `ui/bekkan/__init__.py`（Mixed，已批准）：追加几何面板，成对注册/反向注销。
- `tools/test_geometry_tools.py`、`tools/test_geometry_tools_ui.py`：隔离后台及真实 GUI 验证。
- 本日志与 `开发计划/模块归属标注.md`。

只处理所选 GeometryNodeGroup 节点的 INPUT 接口。已有连接保留，不修改被引用节点组本身。
关联 Panel 按源顺序复制，保留嵌套、描述和默认折叠；同步可开关 Panel 的 toggle 属性。
接口通过原生 `from_socket()` 复制类型、数值单位及范围，再同步接口字段设置和节点当前默认值。
常规重名参数追加编号；多组选中时用组节点名称分 Panel，全部汇入同一个入口。

脚本入口使用节点标记复用，保持原节点位置、选择与活跃节点。新增入口放在左侧并避让已有节点。
重复执行时，已连接的输入不会重复暴露。新入口隐藏无连接的输出，保留必要接线。

带关键帧/驱动的默认值若改成接线，其动画将失去作用，因此这些输入保持原样并计入跳过报告；
不可连接的动态输入也跳过。出现其他异常时移除本次新增接口、Panel、连线、入口和修改器新属性。

## 调试过程

1. 原生探测确认 `from_socket()` 不会把新接口默认值同步给已有外层组节点，可能使参数归零。
   增加外层组用户和直接使用该树的修改器的新参数初始化，已有参数不改。
2. Blender 5.2/5.3 修改器改用 `modifier.properties.inputs.<identifier>.value`；
   旧式 `modifier[identifier]` 不再支持。使用新接口并保留能力检测后的旧版本兜底。
3. 接口根层的 parent 是隐藏 root Panel，非 None；识别根层，避免生成多余空分组。
4. 可开关 Panel 的 toggle 名称由 Blender 自动同步为 Panel 名称；Menu 默认值使用选项名称，
   选项由下游连接传播，连接后才设置默认值。没有选项的 Menu 不设置空默认项。
