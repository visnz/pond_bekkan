# Shader 与输出无关节点筛选

## 目标与范围

- 按用户截图识别「内部有连线、整体不通向输出」的四节点悬空分支，方便筛查和手动删除。
- 在 Shader Editor 材质模式的「别馆 → Shader 脚本」增加「选择与输出无关的节点」。只改变选择和活动节点，不删除节点、不改连线或参数，支持撤销。
- 使用当前材质的实际编辑层，兼容固定材质及进入节点组；不递归修改引用组内部。
- 已遵循用户技能库 `blender/addon-development/SKILL.md`、项目 AGENTS.md、合并对照清单及模块归属标注。本次仅扩展两个现有 New 模块，未改 Mixed 或 Pond 文件，共同维护清单无需调整。

## 修改文件与函数

- `core/shader_tools.py`：新增 `_driver_referenced_nodes()`、`select_nodes_unrelated_to_output()`、`NODE_OT_select_unrelated_shader_nodes_visn`，追加本模块注册元组。
- `ui/bekkan/shader_panel.py`：在现有面板追加第三个按钮。
- `tools/test_shader_unrelated_nodes.py`：隔离后台回归与四节点场景夹具。
- `tools/test_shader_unrelated_ui.py`：一次性独立图形实例验证选择、撤销/重做与原生删除。
- `开发计划/模块归属标注.md`：更新两个现有模块的功能描述。

## 判断方式与调试过程

1. 以本层全部 `OUTPUT_*` 和 `GROUP_OUTPUT` 为根反向遍历输入连线；不只检查完全孤立的节点。使用 visited 集合处理循环。
2. 保留非活动输出、不同引擎输出、AOV，以及表面/体积/置换等全部插口的上游。不按 mute、常量、无效连线或未使用组插口做激进裁剪。
3. 框架始终不选；其内部无关功能节点仍正常筛选。共享给有效输出的上游节点保留。
4. 查询原生驱动变量引用，覆盖本树、其他材质内嵌节点树和物体等数据块。被引用节点及上游保留；数字下标或无法识别的节点路径保守保留全树。
5. API 实测发现 `bpy.data.all_ids` 不包含材质内嵌节点树，因此扫描时显式补充；通过 `path_from_id()` 处理含引号与反斜杠的节点名称。
6. 无输出时取消并保持原选择；零候选时清空旧选择和活动节点，避免将之前选中的有效节点误当作筛选结果。
7. Blender 5.2.4 LTS 实测确认 `RESTRICT_SELECT_OFF` 图标存在。后台测试和图形实例测试均首次通过。

## 验证结果

- 后台六组测试通过：四节点悬空链与共享上游、删除后有效分支完整、多引擎/非活动/AOV 输出、体积和置换、节点组与嵌套框架、无输出取消、零候选清空、循环与 mute、内部/外部驱动及特殊名称/数字下标。
- 独立图形实例通过：面板三个按钮实际绘制；操作器精确选中四个节点；撤销恢复旧选择，重做恢复筛选；调用原生删除后有效输出分支完整，撤销可恢复；零候选和无输出分支符合预期。
- 查看了 `temp/shader_unrelated_selected.png`、结果 JSON 和标准错误输出。没有新增异常；有项目已有的 SnapPanel 命名警告及 Blender 绘制耗时提示。
- 改动 Python 文件编译检查与 `git diff --check` 通过。
- 全部测试使用 factory-startup 隔离实例，未改动、保存或重载用户当前工程。
