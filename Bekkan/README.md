# Bekkan_visn
> 本脚本由 Kimi & visnz 开发。当前版本：1.3.0
>
> ⚠️ **重要：本插件目前仅支持 Blender 5.2**。所有版本判断代码已注释，直接锁定 5.2 分支；其它 Blender 版本不再支持（`bl_info` 已声明最低 5.2，旧版不会加载）。

## 主要功能
（原本只打算制作一个IPR对比工具，后面也把常用的功能集成进去了）

1. IPR渲染快照
2. 上下级操作
3. 搭建、灯光工具（摄像机组 / 约束灯光 / 清理空物体）
4. 贴图索引
5. Wiggle 动画
6. 渲染预设管理

> 页面最下方另内嵌了说旧的插件管理面板「颈椎拯救者 by 说旧」，用于扫描、收藏、排除各类 N 面板插件。

github项目右上角 Code - Download ZIP下载，按照常规方式安装即可。

# 1. IPR渲染快照

## 需求与解决
1. 需要一个能对比在做出某些调整之后，可以对比前后差别的工具，类似OctaneRender的IPR`store buffer`
2. 需要保存多个结果，可以前后比较。每个窗口可以独立保存一组结果。

实现：拍摄时用 `GPUOffScreen.draw_view3d` 离屏重画当前视口到显存纹理（面板等 UI 天然不入镜），再用 GPU shader 叠加到窗口做前后对比；快照只存显存、会话级，不落盘、不随 .blend 保存

## 使用

插件位置：3D Viewer 右侧边拉「别馆」（快捷键：`n`）

![插件位置](src/img1.png)

1. 按 ` Ctrl+Alt+右键 ` 拍摄。只截取当前区域 3D 视口的画布本体（不含顶栏/侧栏等界面）
2. 按住 `Alt+右键 ` 触发对比查看。

3. 在侧边栏可以显示不同拍摄结果

4. 支持多屏幕通过选择图片切换检查

5. 快照图片保存在系统临时目录（`temp/bekkan_snapshots/`），不随 .blend 保存、不会弹"是否保存"提示，关闭 Blender 后自动清除。


## 注意事项
1. 快照叠加与显示基于 5.2 的色彩链路校准（离屏捕获 + sRGB 预解码画回）
2. Eevee下效果较差，未完全采样的情况下拍摄，容易拍到完全低采样的图。降低viewport采样，等到窗口完全采样完成再进行拍摄。
3. 仅支持 **Blender 5.2**（版本判断已注释，其它版本不再支持）
4. 不支持跟随窗口缩放



# 2. 小工具箱

## 使用

所有功能默认开启，无需在偏好设置中单独启用。

插件位置：3D Viewer 右侧边拉「别馆」（快捷键：`n`），按功能分为【快照】【上下级】【搭建类】【贴图索引】【动画类】【渲染预设】六个面板，最下方是「颈椎拯救者 by 说旧」。


## 2.1 上下级操作
1. 【所选物体 到上级】：类似于C4D的`alt+g`的打组功能，用于整理和控制移动

2. 【所选物体 单独每个到上级】：上个功能的单体版，适合用于创建保护动画，比如摇晃和移动进行分离。

3. 【选择所有上级】：blender默认的`shift+g`只能选择一个物体的上级。适合需要选择多个物体移动但不想一个个找上级的情况

4. 【释放到上级】：把选中对象的自己全部释放到上级

5. 【拎出】：多级中间，需要单独拎出一个对象。不再需要进行多次重新链接

6. 【拎出并删除】：把拎出的对象删掉

7. 【创建对焦物体】：为当前摄像机生成一个子空物体作为景深对焦对象，并自动开启景深与外围遮黑，便于灯光 / 摄像机 DOF 快速指向

8. 【单体迁移动画 到上级】：仅单选一个物体时可用。在物体锚点创建上级空物体包裹它，并把该物体的动画（PSR 等 Action 曲线）整体迁移到上级空物体上，原物体变为静止、由上级驱动。

## 2.2 搭建类操作

1. 【C-P摄像机组】围绕选中物体创建一个Central-Protection摄像机组（摄像机P+R锁定），可以通过移动Protection，制作简单围绕圆心的动画
![C-P摄像机组](src/img14.png)

2. 【C-SP-ZT朝向摄像机组】在C-P摄像机组的基础上，补齐了Stare注视层、Zup对象、DOFTarget对焦对象，添加了世界空间、摄像机空间和朝向单独控制的三层对象功能
![C-SP-ZT朝向摄像机组](src/img15.png)

3. 【中心约束灯光】在所选物体中心创建一个「约束灯光组」空物体，其下生成带 Damped Track 约束的灯光，始终朝向目标

4. 【清理空物体】一键删除场景中没有内容的空物体（Empty），自动保护集合实例与含非空下级的对象，便于清理辅助对象

## 2.3 贴图索引

针对导入资产后各种乱七八糟贴图，不知道引用和被使用情况
需要一个工具来整理哪些贴图被哪些材质球使用

![材质图筛选](src/img22.png)

第一步是建立索引

![材质图筛选](src/img23.png)

选中贴图之后，点击查找，即可知道被哪些材质引用。

可以选中这些全部对象（Edit模式下不行，如果不在当前场景也无法被选择）

## 2.4 动画类

Wiggle动画，类似于AE的Wiggle动画，支持位置 / 旋转 / 缩放三种目标属性，通过添加噪波修改器完成。
点击后弹出参数面板，可设置缩放、强度、错位范围，每个对象每根轴独立随机取值。
（重复使用会cover掉，即先删除旧的NOISE修改器再加新的）

适合制作飘动动画、飘花、模拟风力等各种情况

【移除全部动画】：移除选中物体上的全部动画数据（含形态键动画），便于快速复位到静态。

## 2.5 渲染预设

点击创建预设，会以一个Final配置，创建4个不同的渲染预设（HD / Style / prev / demo），以挂载在摄像机下的空物体形式保存，另有一个 folder 对象存储相对/绝对路径
![渲染预设](src/img25.png)
需要填入xy、采样、帧范围、帧步长，绝对路径和相对路径（用于一键切换）

创建后即可在面板上点击 HD / Style / prev / demo 按钮一键应用；另可：
- 【从其他 Scene 同步渲染设置】：将另一个场景的渲染配置一键同步到当前场景
- 【打开工程所在文件夹】 / 【打开输出文件夹】 / 【打开插件所在文件夹】：快速打开对应目录
