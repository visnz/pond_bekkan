# PondBekkan（池塘 × 别馆）

Blender 5.2 插件：**一套核心，两套界面**。
池塘（岁岁的 Pond）与别馆（桶桶的 Bekkan）两个工具箱在底层合并维护，
各自的使用者打开时看到的仍是自己熟悉的界面。

- **蛙灾模式** = 池塘 UI：N 面板「池塘」页，四抽屉（🧹整理 / 👁观察 / 🔨制作 / 📦交付）+ 16 个模块开关
- **别馆模式** = 别馆 UI：N 面板「别馆」页，📸快照 + 📋工程分析 + 工具箱五面板 + 颈椎拯救者

仅支持 **Blender 5.2**。

## 发行版本（dist/）

| 版本 | zip | 包名 | 说明 |
|---|---|---|---|
| 合体版 | `pond_bekkan_combined.zip` | `pond_bekkan` | 偏好设置里有「蛙灾模式 / 别馆模式」二选一开关，**默认蛙灾** |
| 蛙灾独立版 | `Pond_standalone.zip` | `Pond` | 无开关，打开即是池塘 UI；包名沿用 `Pond`，旧版 Pond 的模块开关偏好可直接继承 |
| 别馆独立版 | `bekkan_visn_standalone.zip` | `bekkan_visn` | 无开关，打开即是别馆 UI；包名沿用 `bekkan_visn`，直接覆盖旧安装 |

三个版本是**同一份源码**打包出来的，功能底层完全一致，只是界面皮肤不同。
安装：Blender → 编辑 → 偏好设置 → 插件 → 从磁盘安装 → 选 zip。

## 功能清单

### 蛙灾模式（池塘）

| 抽屉 | 模块 |
|---|---|
| 🧹 整理 | 父子级（打组/拎出/释放/选父级）、一键整理（清孤立/合并重复材质/批量原点）、同步体检（小眼睛 vs 渲染一致性 + 法线贴图色彩空间） |
| 👁 观察 | 明度检查（白膜AO/灯光显像/黑白显像）、快照对比、灯光台（标签分组 + solo）、色卡（图片提取调色板 + 悬浮色卡窗） |
| 🔨 制作 | 摄像机组、六面投射、图转立体（位图轮廓挤出）、预设库（几何节点/材质）、烘焙贴图、拆分物体 |
| 📦 交付 | C4D 互导（分组FBX/Alembic/材质清单/Empty还原集合）、版本另存（v### 递增 + 输出路径同步）、分层渲染 |

### 别馆模式（别馆）

- 📸 **快照**：IPR 视口快照对比（与蛙灾模式同一核心）
- 📋 **工程分析**（实验性）：25 项简单检查 + 7 项深度检查，按影响/难易排序，✓/× 标记随 .blend 保存，部分可一键修复
- 👪 **上下级**：到上级 / 迁移动画到上级 / 单独每个到上级 / 选择所有上级 / 释放到上级 / 拎出 / 拎出并删除 / 创建对焦对象
- 🏗 **搭建类**：C-P 摄像机组 / C-SP-ZT 摄像机组 / 中心约束灯光 / 删除无内容的 Empty
- 🖼 **贴图索引**：贴图→材质反查、选中使用该贴图的物体
- 🎞 **动画类**：Wiggle Noise 动画、删除所选对象动画
- 🎬 **渲染预设**：HD/Style/prev/demo 预设、场景间渲染设置同步、快捷打开文件夹
- **颈椎拯救者**（by 说旧）：N 面板插件管理器，把其他插件的面板按类别收纳进「别馆」页

### 快捷键（两个模式通用）

| 快捷键 | 功能 |
|---|---|
| `Ctrl + Alt + 右键` | 拍快照 |
| `Alt + 右键`（拖动） | 拖动快照分割线 |

## 仓库结构

**仓库根目录即插件包根目录**——把整个仓库文件夹复制/链接到 Blender 的
`scripts/addons/` 下（文件夹名保持 `pond_bekkan`）即可直接启用开发，
合体版无需打包。

```
pond_bekkan/          # 仓库根 = 插件包根（复制进 addons 的就是这一层）
├── __init__.py       # bl_info + 注册中心（prefs → core → ui）
├── _build_mode.py    # 构建标记（combined/pond/bekkan，build.py 写入）
├── prefs.py          # 唯一 AddonPreferences（模式切换 + 模块开关 + 颈椎拯救者设置）
├── core/             # 逻辑层：全部 Operator/PropertyGroup，无 Panel
│   ├── analyzer/     #   工程分析（实验性）
│   └── addonmanager/ #   颈椎拯救者核心（仅随别馆模式激活）
├── ui/
│   ├── bekkan/       # 别馆模式 UI
│   └── pond/         # 蛙灾模式 UI（sections 四抽屉 + panels 16 子面板）
├── build.py          # 打包脚本：python build.py → dist/ 三个 zip
├── dist/             # 打包产物
├── tools/            # 诊断脚本（Blender 内运行）
└── 开发计划/          # 设计文档与 合并对照清单.md
```

## 打包

```
python build.py
```

在 `dist/` 下产出三个 zip。打包脚本按白名单只收插件本体
（`__init__.py` / `_build_mode.py` / `prefs.py` / `core/` / `ui/`），
自动写入对应 `_build_mode.py` 并补丁 bl_info 名称；
仓库里的文档、脚本、开发计划等不会进 zip。
